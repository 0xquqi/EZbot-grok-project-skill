# 按机制选择研究路径

来自自有独立研究模块当前14类方法的适配。按实际规则选相关行，可组合；关键词只帮助找到问题，不证明该项目使用此机制。不携带旧项目地址、价格、资格或安全结论。

| 机制 | 研究路径与容易误判的地方 |
| --- | --- |
| Agent ID资格 | 沿入口确认身份注册表与被检查主体；区分持有、owner、handle等要求。拥有身份不代表尚有免费额度。 |
| 直接NFT铸造 | 绑定链、目标合约、完整ABI及继承/实现；追门禁、数量、支付、供应到实际资产与收件人。有mint函数不等于公众可调用。 |
| 白名单/签名领取 | 区分公开、Merkle、签名与持有门槛；核证明绑定的参与者、阶段、数量、价格、期限和nonce。解释官方凭证取得方式，不补造proof或请求签名。 |
| 付费/授权 | 追原生币或ERC20支付、单位与spender；跨档/免费抵扣核总价。本金、授权需求、Gas分开，零报价可能是无效数量或读取失败。 |
| 合成/质押/产出 | 逐项确定输入与数量、销毁/托管/锁定、所有权条件、不可逆性及产物；追后续claim/reveal。增加权重不等于收到可交易资产。 |
| 发射台 | 区分平台、目标资产、版本、曲线/金库/迁移阶段；追买卖、流动性与迁移条件。销售完成不等于已迁移，也不保证能卖出。 |
| 身份/钱包额度 | 定位计数按地址、身份还是tokenId；核不同入口是否共用、转移后是否保留。身份、钱包、每笔和公共限额分别解释，缺个人信息不填剩余额度。 |
| 数量/附赠 | 分开输入数量、计费数量、主要产物和赠品数量及单位；核供应与计数扣减，是否另领。返利或信用不等于多铸NFT。 |
| 动态报价/随机性 | 区分价格预言机和随机请求；核精度、时效、舍入与预算，追回调/reveal、实际消耗和退款。请求受理不等于最终产物可用。 |
| PoW | 查挑战与哈希绑定的主体、链/合约、难度、过期和已用状态；确认proof输入及产物类型。不计算或提交工作证明，不套用历史nonce。 |
| 募资/退款 | 找收款/托管、账本、阶段和退款权限；核期限、扣减公式、收件人与主动领取要求。有refund函数不等于当前能退全款。 |
| 签名支付/中继 | 确认实际协议及签名域、链、验证合约、付款/收款主体、金额、期限、nonce；追付款到业务结算及恢复。批次成功不代表每单成功，签名支付不等于普通allowance。 |
| 多阶段消耗 | 区分必需/可选步骤，逐步列前置、等待、销毁/锁定、追加费用、产物与完成条件；仅说明目标支持的恢复路径。前一步成功不等于整个活动完成。 |
| 代币领取/铸造 | 确认NFT、ERC20增发、库存转账或内部积分；核单位转换、接收者及额度来源。应计/可领取数不等于已到账，mint名称不能证明资产类型。 |

发现未知机制时，从本轮原始资料解释输入、条件、状态变化与产物，再决定该查什么，不把清单当作能力上限或强行套入旧类别。
